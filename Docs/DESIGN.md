# 《NOI 乱斗》设计笔记

## 一句话

在第一题已经通过、第二题不会做的情况下，利用考场里的一切互动，在监考视线下拼出真正的解题思路。

## 情绪

“严肃竞赛”与“荒诞潜行”并置：整齐的机位、冷静的监考、发光的成绩板，以及玩家不断冒出的歪主意。

## 核心循环

1. 观察巡逻路线。
2. 探索并收集三条灵感线索。
3. 选择制造噪音、关灯或借助环境来创造空隙。
4. 在怀疑度爆表前抵达评测终端并提交思路。

## 三条线索

- 白板：从“反向边 + 离线询问”想到把问题离线化。
- 废纸篓：草稿纸上的“分块、倍增、合并”。
- 邻座选手：把三次启发式搜索看成三次独立观察。

最终把三者合成“离线分块 + 多次起点”的灵感。游戏用幻想化的终端提交表现这一过程。

## 结局

- **金牌结局**：收集全部线索，完成第二题真正的关键推导。
- **零分结局**：被监考抓个正着。
- **隐藏结局**：在侧区找到被遗忘的选手手册，先理解规则，再回到考场。
